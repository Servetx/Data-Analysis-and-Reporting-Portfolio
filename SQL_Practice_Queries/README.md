# SQL Practice Queries

[← Ana sayfa](../README.md)

Bu klasor, Olist Brazil e-ticaret veri seti uzerinde yaptigim temel SQL pratik sorgularini icerir.

Bu dosyalar is odakli ana proje degil; SQL konularini ogrenmek ve pekistirmek icin hazirlanmis calisma dosyalaridir.

## Veri Kaynagi

[Brazilian E-Commerce Public Dataset by Olist (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Bu pratiklerin is sorularina uygulanmis hali: [E-Commerce Business SQL Analysis](../Ecommerce_Business_SQL_Analysis/README.md)

## Dosyalar

| Dosya | Icerik |
| --- | --- |
| [`Basic.sql`](Basic.sql) | Temel SELECT, filtreleme, siralama ve veri kontrolu sorgulari |
| [`Aggregate_Functions.sql`](Aggregate_Functions.sql) | COUNT, SUM, AVG, MIN, MAX gibi aggregate fonksiyon pratikleri |
| [`Joins.sql`](Joins.sql) | Tablolari JOIN ile birlestirme calismalari |
| [`Common_Table_Expression.sql`](Common_Table_Expression.sql) | WITH / CTE kullanimi |
| [`Subquery_and_Deep_Filter_Analysis.sql`](Subquery_and_Deep_Filter_Analysis.sql) | Alt sorgu ve detayli filtreleme pratikleri |
| [`Window_Function_Expression.sql`](Window_Function_Expression.sql) | ROW_NUMBER ve window function pratikleri |
